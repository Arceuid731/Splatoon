## Validation

- **67 tests réussis**, dont tests du véritable installateur dans un hôte simulé et tests de sélection entre sources concurrentes.
- Plugin complet compilé en **Release/x64**, SDK .NET 10.0.102, bibliothèques Dalamud locales API 15 : aucune erreur. Des avertissements du projet et des dépendances subsistent.
- **5 057 entrées** des neuf caches utilisateur réindexées : **5 057 conservées**, aucune modification de leurs correspondances de territoire.
- Présélection calculée sur **489 territoires** du catalogue combiné ; Éden Déluge normal propose une seule entrée, `E3` issue du dossier anglais de Hibiya615, cochée par défaut.
- Dix dépôts candidats téléchargés et inspectés. Les huit sources contenant des presets exploitables ont été ajoutées et activées, selon la demande de Yann. Les réglages des neuf sources existantes sont conservés.
- Archive générée vérifiée pour sa version et ses DLL.

Le plugin n'a pas été chargé dans FFXIV pendant l'audit. Les tests de l'installateur simulent l'importeur et le compilateur ; ils ne valident pas les timings ni le rendu d'un combat. Essais restant à réaliser en jeu : entrée d'instance, import/remplacement/désinstallation, persistance après redémarrage, compilation d'un script valide et d'un script erroné.

## Éden Déluge : preset trouvé

**E3N, territoire 851**, est présent dans [Hibiya615 — Normal Raids, édition anglaise](https://github.com/Hibiya615/Splatoon_Presets/blob/main/%5BEN%20Set%5D/Normal%20Raids.md), révision `b997ab13089d34b0bf67d90c9009405e6bf42610`.

L'entrée `E3` contient dix éléments : capture du marqueur de tankbuster, ligne du tankbuster, knockback Tidal Wave, deux Undersea Quake, Spinning Dive, flaques grandissantes et aides Stormy Horizon. Le ciblage utilise principalement des IDs numériques, buffs et VFX. Les propriétés utilisées existent dans le Splatoon compilé. Les indications sont principalement anglaises ; leur comportement en combat sur client français reste à vérifier.

Territoires confirmés dans les données : [851 normal](https://v2.xivapi.com/api/sheet/TerritoryType/851?fields=ContentFinderCondition.Name&language=fr), [855 sadique](https://v2.xivapi.com/api/sheet/TerritoryType/855?fields=ContentFinderCondition.Name&language=fr). Aucun E3S trouvé dans les dépôts inspectés ; ce n'est pas une preuve d'absence ailleurs.

Le [wiki Raids de cptjabberwock](https://github.com/cptjabberwock/SplatoonPresetsList/wiki/Raids) ne listait que E2N et E11N pour Éden normal. Il référence aussi des auteurs et Discord : scanner son dossier `Community Presets/` ne récupère pas automatiquement tous ces liens externes.

## Limites du choix automatique

Les copies identiques sont dédoublonnées. Pour les versions différentes, la présélection évite les recouvrements détectables par IDs de mécanique ; elle préfère les versions anglaises et les ensembles plus complets. Elle ne peut pas démontrer que deux dessins sont équivalents. Un recouvrement partiel peut laisser une partie unique non cochée ; des overlays sans IDs comparables peuvent toujours se recouvrir. Les alternatives restent sélectionnables manuellement.

Les instantanés et rapports détaillés sont dans `artifacts/source-audit*`, `artifacts/baseline-audit` et `artifacts/final-audit`, ignorés par Git. Aucun preset tiers n'est incorporé au ZIP du plugin.
